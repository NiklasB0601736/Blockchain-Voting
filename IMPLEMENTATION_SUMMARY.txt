SICHERHEITSMECHANISMEN
======================

1. ANONYMITÄT (Semaphore)
   - Wähler registrieren mit Commitment (nicht Identität)
   - Zero-Knowledge Proofs beweisen Berechtigung
   - Vote kann nicht zur Person zurückverfolgt werden
   - Impact: ✅ ERFÜLLT - Alle Nutzer sind anonym

2. BLOCKCHAIN-INTEGRITÄT
   - SHA-256 Block Hashing für Tampering-Detection
   - Proof-of-Work Konsens (5 führende Nullen)
   - Linked Block Chain mit Previous Hash
   - Chain-Validierung: GET /api/blockchain/valid
   - Impact: ✅ ERFÜLLT - Integrität verifizierbar

3. DOPPEL-ABSTIMMUNG VERHINDERT
   - registered_voters Set pro Election
   - Voter Commitment kann nur 1x registriert werden
   - Impact: ✅ ERFÜLLT - Double-Voting unmöglich

4. ÖFFENTLICHE TRANSPARENZ
   - GET /api/results/{id} ohne Authentifizierung
   - GET /api/verify/{id} öffentlich aufrufbar
   - Gesamte Blockchain einsehbar: GET /api/blockchain/chain
   - Impact: ✅ ERFÜLLT - Jeder kann auswerten

API REFERENZ
============

ÖFFENTLICH (keine Auth erforderlich)
====================================

GET /api/elections
  Alle Wahlen auflisten
  Response: { elections: [...], total: N }

GET /api/elections/{id}
  Wahl-Informationen abrufen
  
GET /api/results/{id}
  ★ WAHLERGEBNISSE AUSWERTEN (JEDER kann!)
  Response: { title, options, results: [{option, votes}], total_votes }

GET /api/verify/{id}
  ★ INTEGRITÄT VERIFIZIEREN (JEDER kann!)
  Response: { total_votes, total_counted, integrity_valid, blockchain_valid }

GET /api/blockchain/chain
  Gesamte Blockchain einsehen
  
GET /api/blockchain/valid
  Blockchain-Validität prüfen

GET /api/health
  System-Status

ADMIN (benötigt X-Admin-Key header)
===================================

POST /api/elections
  Neue Wahl erstellen
  Body: { title, options[], duration }

POST /api/elections/{id}/finalize
  Wahl beenden und Ergebnisse speichern

BENUTZER (offen)
================

POST /api/voters/register
  Wähler mit Commitment registrieren
  Body: { election_id, voter_commitment }

POST /api/vote
  Anonymen Vote abgeben
  Body: { election_id, vote_option, voter_commitment }
