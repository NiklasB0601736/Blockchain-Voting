QUICK START - BLOCKCHAIN VOTING SYSTEM
======================================

INSTALLATION
============

1. Virtuelle Python-Umgebung anlegen:
   $ python3 -m venv .venv

2. Dependencies installieren:
   $ .venv/bin/pip3 install -r requirements.txt

3. Server starten:
   $ ADMIN_KEY=dev_admin_key .venv/bin/python blockchainV1.py

   Falls Port 5000 belegt ist:
   $ PORT=5001 ADMIN_KEY=dev_admin_key .venv/bin/python blockchainV1.py

4. Frontend öffnen:
   $ open frontend.html

   Wenn du PORT=5001 nutzt, im Frontend die API URL auf
   http://127.0.0.1:5001 setzen.


ERSTE WAHL DURCHFUEHREN
=======================

A. Backend pruefen
------------------

1. Im Frontend "Status prüfen" klicken.
2. Bei Bedarf API URL korrigieren.

B. Admin: Wahl erstellen
------------------------

1. Admin-Key eintragen:
   dev_admin_key

2. Formular ausfüllen:
   - Titel: Test Wahl
   - Optionen: Ja, Nein, Enthaltung
   - Dauer: 60 Minuten

3. "Wahl erstellen" klicken.
   Die Wahl-ID wird automatisch in die anderen Felder übernommen.

C. Waehler: Registrieren und abstimmen
--------------------------------------

1. MetaMask verbinden oder ein eigenes Commitment eintragen.
2. "Registrieren" klicken.
3. Wahloption auswählen.
4. "Vote abgeben (ANONYM)" klicken.

Hinweis: Dasselbe Commitment kann pro Wahl nur einmal abstimmen.

D. Ergebnisse
-------------

1. Als Admin "Wahl beenden" klicken.
2. "Ergebnisse abrufen" klicken.
3. "Verifizieren" klicken.


TESTS AUSFUEHREN
================

$ python3 test_voting.py

oder mit der virtuellen Umgebung:

$ .venv/bin/python test_voting.py

POST /api/vote
POST /api/elections/{election_id}/finalize Header: X-Admin-Key
GET  /api/results/{election_id}
GET  /api/verify/{election_id}


HINWEIS ZUR SICHERHEIT
======================

Die Python-App ist eine lokale Demo. Sie verwendet Commitments und Hashes,
aber noch keine echte Semaphore-Proof-Erzeugung und keine echte On-Chain-
Verifikation. Der Solidity Contract ist der Startpunkt fuer diese naechste
Ausbaustufe.
